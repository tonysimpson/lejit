# File map and coverage record

One row per file. **Every file has been read in full at least once.** The "reviewed" column gives the commit it was reviewed at; if the file has changed since, re-review it.

- Layers are `core`, `translated`, `backend`, `glue`, `tooling` and `obsolete` (see `GOAL.md`); a mixed file lists several. For the files INVENTORY.md split function by function, the layers follow its line counts: the larger of core and translated first, a part under about a tenth of the file left out, and glue named only where it is most of the file. `b36a1ac` in the reviewed column is that inventory's read (every line, against 3.7.17).
- Only the complex files carry an explanatory comment at the top. Simple files have none, and their row here is the only summary.
- Breakdowns by function for the big mixed files are in `ARCHITECTURE.md` ("The mixed files, by section").
- Translation patterns are in `PATTERNS.md`.
